FE07 — Kết quả triển khai và kiểm thử

24/11/2026 · feat/task-cancellation · Chưa commit/push đợt FE07

Luồng hiện tại: đến pickup → chờ Operator xác nhận → vận chuyển → đến delivery → chờ xác nhận → robot báo hoàn thành. Tiến độ và bằng chứng được lưu vào PostgreSQL.

Phạm vi đã thực hiện

  • Assignment atomically snapshots the route, map revision, station QR expectations and optional package code before publishing.
  • AT_PICKUP waits for Operator QR/manual physical-loading confirmation; only then may navigation to delivery continue.
  • AT_DELIVERY waits for unloading verification; final robot event is required before task/assignment completion and robot release.
  • QR mismatches are logged and keep the robot stopped; manual verification requires a reason and explicit physical confirmation.
  • UUID/request fingerprint makes identical retries idempotent; altered payload under the same ID is rejected.
  • Serializable transactions, cursor concurrency token, fresh camera/stopped reports, robot health and safety holds guard state transitions.
  • Mission route/cursor, ordered waypoint arrivals, scan events, attempts, final verification, status history and audit actor/time/state persist to DB.
  • GET mission list/detail and Operator verification UI show persisted progress, results and history; Admin/Maintenance cannot submit verification.
  • Recovery reads durable pickup evidence after restart; legacy unknown assignments remain fail-closed.

Quy tắc triển khai

  • expectedQr: Stations.QrCodePayload snapshotted at dispatch; ArUco navigation IDs are separate.
  • package: When a task has PackageCode, QR-mode verification must also match that package code.
  • manualRole: Warehouse Operator, following UC06; reason and physical-transfer confirmation required.
  • maxQrAttempts: Verification:MaxQrAttempts, default 3, configurable 1–20; numeric default is an implementation choice, not a number specified by BA.
  • stationFreshness: Stopped camera report within 15 seconds and received after backend process start.
  • stationPlacement: Pickup/delivery stops must be outside reserved intersections.

Giới hạn nghiệm thu

  • The legacy JetRacer/ROS CIRCLE adapter has not been ported or hardware-tested for this handshake.
  • Persistence retains evidence; navigation epoch changes/reconnects still stop for Maintenance recovery. Automatic physical resume after restart remains separate work.
  • Station-to-ArUco commissioning must match the real layout; general warehouse/station CRUD and map-version management remain in the broader backlog.
  • UI accepts keyboard/USB scanner payloads. No phone-camera scanner or physical load sensor is implemented.
  • These tests do not mark all 152 planned acceptance cases as passed; broader performance, multi-robot, hardware and soak acceptance remain.
